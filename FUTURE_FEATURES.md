# 🔮 Roadmap & Évolutions Futures

Voici la liste des fonctionnalités planifiées pour les prochaines versions de la plateforme AUTOMATIC.

## 🛠 Backend & Core
- [ ] **Système de Notification Push** : Alertes directes sur le navigateur pour les nouveaux messages.
- [ ] **Webhook Integration** : Envoyer les nouveaux projets vers un canal Slack ou Discord.
- [ ] **Facturation Automatisée** : Intégration de Stripe pour le paiement des briques technologiques choisies.
- [ ] **Gestion des Versions** : Historisation des contrats signés pour chaque projet.

## 💻 Dashboard Client
- [ ] **Gestion Dynamique des Profils** : Rendre la page `/dashboard/settings` interactive pour permettre aux clients de changer leur mot de passe et leurs préférences.
- [ ] **Explorateur d'Assets** : Zone dédiée pour télécharger les documents techniques, les maquettes Figma et les codes sources.
- [ ] **Timeline Visuelle** : Remplacement du simple pourcentage par une frise chronologique interactive (Gantt simplifié).

## 💬 Communication
- [ ] **Appels Vidéo Intégrés** : Utilisation de WebRTC ou Jitsi pour les sessions de cadrage hebdomadaires.
- [ ] **Système de Tickets** : Pour la maintenance post-déploiement.
- [ ] **IA Copilot** : Un assistant IA qui peut répondre aux questions basiques du client sur l'avancement technique.

## 🎨 UI/UX
- [ ] **Mode Clair / Sombre Automatique** : Support du thème système.
- [ ] **Accessibilité (A11y)** : Audit complet pour garantir l'utilisation par tous.
- [ ] **Animations de Succès** : Utilisation de Lottie pour les validations de contrats et fin de projets.

## 🏗 DevOps
- [ ] **Déploiement en 1 Clic** : Automatisation du déploiement Vercel/Supabase pour les nouveaux clients staff.
- [ ] **Monitoring Sentry** : Suivi des erreurs temps réel pour une réactivité maximale.
